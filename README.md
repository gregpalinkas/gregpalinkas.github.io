# gregpalinkas.github.io

Portfolio of Gregory Palinkas. Static site, no build step: `index.html` + `assets/`.

- Copy and sections: `index.html`
- Styles: `assets/site.css` · Hover diagrams: `assets/diagrams.js` · Gallery + hero rack: `assets/site.js`
- Gallery images: `assets/img/<set>-NN.jpg` (`-01` is each tile's cover; tiles with a missing cover are hidden)
- Legrand sets: `legrand-inplace-NN`, `legrand-render-NN`, `legrand-unreal-NN` (prepped to 2000 px, metadata stripped)

Published by GitHub Pages from `main` / root.
